# shhh · 백색소음

여러 소리를 섞어 나만의 백색소음을 만드는 웹 앱(PWA)입니다.
음원 파일 없이 모든 소리를 브라우저의 Web Audio API로 실시간 합성합니다.

<img src="docs/screenshot.png" width="320" alt="스크린샷">

## 기능

- 8가지 소리: 화이트 / 핑크 / 브라운 노이즈, 빗소리, 파도, 선풍기, 모닥불, 깊은 저음
- 소리별 볼륨 조절 + 동시에 여러 소리 믹스
- 꺼짐 타이머 (15분 ~ 2시간, 끝나기 20초 전부터 서서히 줄어듦)
- 설정 자동 저장 (마지막 믹스와 볼륨 기억)
- 홈 화면에 추가해서 앱처럼 사용, 오프라인에서도 동작
- 잠금화면/이어폰 버튼으로 재생·정지 (Media Session)
- 키보드 스페이스바로 재생/정지

## 실행

빌드 과정이 없는 정적 파일이라 아무 웹 서버로 열면 됩니다.

```sh
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

휴대폰에서 쓰려면 GitHub Pages 등에 올린 뒤 브라우저 메뉴에서 **홈 화면에 추가**를 누르세요.
(서비스 워커는 HTTPS 또는 localhost에서만 동작합니다.)

## 파일 구조

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구성 |
| `style.css` | 스타일 |
| `noise.js` | 소리 합성 (각 소리를 끊김 없이 반복되는 버퍼로 생성) |
| `app.js` | 재생, 믹서, 타이머, 저장 |
| `sw.js` | 오프라인 캐시 |
| `manifest.webmanifest`, `icon.svg` | PWA 설정과 아이콘 |

새 소리를 추가하려면 `noise.js`의 `sounds` 배열에 생성 함수와 함께 항목을 하나 추가하면 됩니다.
